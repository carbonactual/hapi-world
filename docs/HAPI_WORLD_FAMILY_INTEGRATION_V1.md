# HAPI World Family Integration v1

This repository is part of the HAPI World family. It does not compete with HAPI or HAPI World Nexus as a separate constitution.

## Family

- `B3C0M1NG/HAPI` — human/API and identity boundary.
- `B3C0M1NG/hapi-world` — HAPI World implementation lineage.
- `carbonactual/hapi-world` — HAPI World domain/specification and product surface.
- `carbonactual/hapi-world-nexus` — historical Nexus/integration/audit lineage.

## Local responsibility

This repository owns HAPI World domain behavior, specifications and world-facing composition that belongs below the OMNII constitutional layer.

## Required inheritance

Identity, authority, consent, provenance, Proof, Actual, Pulse, Value, Continuum, Root, Index, Vault and horizon semantics come from shared ecosystem contracts rather than being redefined here.

## Free/open rule

New core capabilities must use free/open-source, self-hostable or open-standard implementations. Commercial providers are optional adapters only.

## Safety

HAPI World remains AI-native. Human consequences cross through governed HAPI/SEAL boundaries. Future, simulated and unknown states never silently become Actual.
