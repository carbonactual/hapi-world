# Carbon Actual — Universal Interoperability Layer (UIL)

## Definition

The Universal Interoperability Layer (UIL) is the constitutional interoperability infrastructure of the Carbon Actual Ecosystem.

It enables every identity, AI, agent, institution, protocol, application, blockchain, ledger, network, cloud, marketplace, device, robot, service, model, API, and future technology to communicate, exchange value, collaborate, and operate through one constitutional standard.

No technology is excluded by design.

Any technology that satisfies Carbon Actual constitutional requirements may participate.

The UIL is technology-neutral.
