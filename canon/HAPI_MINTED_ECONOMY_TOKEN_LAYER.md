# The Minted Economy — Pulse, Value, Tokenization & HAPI Bank (Oct 24, 2026)

**Document type:** Final integration layer — everything minted, tokenised, financed
**Status:** Draft v1 — HELD UNDER COMMIT FREEZE

## 1. The Mint System — every value unit becomes an instrument

Nothing in the ecosystem stays a "stat". Every verified unit of value mints a ledger record:

- **Pulse mints** — each verified value-used event mints a Pulse record. Engagement becomes ledgered value, never vanity.
- **Work mints** — every content asset mints with content_hash provenance (ownership receipts; originals provable, fakes detectable).
- **Proof mints** — claims, credentials, badges, ranks. Earned only, never purchasable. Receipts attached.
- **License mints** — permission states as tradeable rights records (clip / repost / sync / exclusive / ai_likeness, term, territory, share).
- **Identity mints** — the # namespace: verified personhood (or verified-ANONYMOUS personhood) portable across every platform.
- **Credit mints** — earned credits, wallet balances, prepaid fan credits.
- **Claim mints** — receivables, revenue shares, future-work units. FINANCEABLE instruments.

## 2. Decimalized tokenization (constitutional mechanics)

- Fractionalized to fine grain: a catalog in 1,000 units; the next work pre-sold in units; guild capacity pooled in units.
- Decimalized logic: value tracked to the decimal, per full-cost accounting (wear, time, energy, distance, depreciation).
- Blockchain-ready, never blockchain-dependent: Postgres + event ledger first, mint-reference fields throughout the schema.
- Settlement graph: every minted unit declares its settlement method + finality state (the Market Universe Canon's 23-state lifecycle).

## 3. HAPI Bank — the creator financing core

Products (all underwritten by mints, not vibes):
1. **Income smoothing** — advances against verified claim mints (lumpy brand income → steady salary).
2. **Factoring** — buy verified receivables at fair value (kills the 26% delayed-payment problem).
3. **Community pre-financing** — fans buy credit units at discount before the work exists. Zero-debt financing; demand proven before production.
4. **Guild credit circles** — P2P 0% borrow/lend within verified collectives (already prototyped in NOUN Premium).
5. **Equipment financing** — gear as banked assets with depreciation ledgers; capacity-backed.
6. **Escrow custody** — booking/sponsorship funds in the settlement graph. Fraud starves.
7. **Vaults** — media custody doubles as collateral custody (asset + proof in one store).

Regulatory posture (fixed lines): ledger + underwriting layer OVER licensed PSP rails (Flutterwave/NGN). Never a deposit-taker; never unlicensed lending. Anything investment-facing goes through the SEC Nigeria compliance path before launch. Consent-first is NDPA-native.

## 4. The trinity — ownership, permission, access

- **Ownership** = mints (who owns the value unit, provable)
- **Permission** = license mints + consent records (what may be done with it, by whom, where, until when)
- **Access** = scoped grants (who may act on behalf of whom — staff, family, agents — audited, expiring, revocable)

The trinity is simultaneously the security architecture and the product architecture. No platform on earth offers all three to a creator. HAPi's are already live entities.
