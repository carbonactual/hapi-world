# Canon Extension — Product Domain Catalog

> **Status: Draft catalog / conformance index.** This document describes the product universe; current implementation truth is tracked in `carbonactual/omnii` via `docs/architecture/OMNII_PRODUCT_CONFORMANCE_MATRIX.md` and the live product conformance registry. Do not infer production activation from catalog presence alone.

## Common denominators

The product universe composes the OMNII Common Layer v1.0.0:

Identity · Relationship · Intent · Capability · Discovery · Matching · Context · Availability · Lifecycle · Trust · Authority · Authorization · Resource · Property · Rights · Value · Exchange · Market · Offer · Order · Transaction · Settlement · Management · Communication · Document/Evidence · Workflow · Location/Time · Compliance/Risk · Analytics/Learning · Interoperability.

ABBA coordinates intelligence and orchestration but is not an authority issuer. Products do not create alternate identity, authority, graph, workflow, execution, evidence, value or ledger foundations.

## Composition rule

All products follow:

`OMNII Core + Common Layer + Shared Capabilities + Domain Module + Institutional Configuration + Data + Policy/Rules + Integrations + Presentation`

and the preferred reuse path:

`reuse → configure → compose → extend domain contract → create shared capability only when genuinely new → constitutional amendment only when foundational semantics are missing`.

See `carbonactual/omnii/docs/architecture/OMNII_PRODUCT_CONFORMANCE_MATRIX.md` for the authoritative mapping and live product registry.
