## What's actually next
Before building any of these as code: pick ONE and build it end-to-end against this spec, rather than starting forty-seven simultaneously. **BUNK** remains the strongest first candidate — it already has a scoring algorithm and API spec from prior work (see `knowledge/EXTRACTED_FROM_OMNII.md`). **Direct Bank OS/App** is also worth prioritizing given it maps directly to ABBA's real-world role as Acting Head of Operations at an actual microfinance bank — that's the one domain here with genuine domain expertise already in hand, not just architecture.

The failure mode from the earlier extended discussion this catalog was extracted from was breadth claimed instantly, depth never delivered — 47 products "activated" in a single reply with zero code. Don't repeat that pattern here.
