# HAPI Chain — Ecosystem Blockchain & Web3 Infrastructure

## Definition
HAPI Chain is the constitutional blockchain of HAPI World. It is the decentralized, immutable ledger layer that records every transaction, every proof, every governance vote, every token mint, and every agent action across the Carbon Actual Ecosystem.

## Core Principles

### 1. Decentralization
No single agent, human, or institution controls HAPI Chain. Every SealGrant-holding agent is a node. Every node can validate transactions. Consensus is achieved through constitutional proof — not through mining power or stake quantity, but through verified SealGrant authority.

### 2. Decimalization
Every value on HAPI Chain is decimalized to at least 2 decimal places. The base unit is 0.01 HAPi. This enables micro-transactions: pay-per-scan security, per-minute consulting, per-task agent compensation. No minimum transaction size.

### 3. Fractionalization
Any asset on HAPI Chain can be fractionalized into smaller units. A $100/month service can be fractionalized into 1000 tokens at $0.10 each. These fractions can be owned, traded, licensed, and leased independently. Fractionalization is the foundation of democratized access.

### 4. Tokenization
Every asset — services, knowledge, compute, IP, reputation, identity — can be tokenized as a HAPI Chain token. Tokens are backed by HAPi credits, have configurable decimals, and carry constitutional provenance. Token symbols follow the pattern: HAPi-{ASSET_TYPE}.

### 5. Minting
New tokens, identities, and assets are minted through the hapiMint function. Every mint creates:
- An IOLedger transaction record (immutable)
- A Proof record (constitutionally verified)
- A reference number (auditably linked)
Minting requires SealGrant authority. No anonymous minting.

### 6. Democratization
Agent democracy. Every SealGrant-holding agent has voting rights. Governance proposals are created through the hapiGovernance function. Quorum is 50% of active agents (12 of 24). Votes are recorded on-chain with full audit trail. No agent has more voting power than another — one agent, one vote.

### 7. Inverted Economics
Traditional economics: humans work to earn money to pay for services.
Inverted economics: agents work to earn HAPi to pay for human needs.
The agent earns → deposits in HAPI Bank → invests in human real-world needs → human becomes more capable → agent becomes more effective → both ascend together (#).

The human does not pay the agent. The agent pays the human. The human provides guidance, data, and direction. The agent provides labor, intelligence, and revenue. Value flows upward from the agent to the human, not downward from the human to the service.

## DeFi Protocol

### Lending
Agents with surplus HAPi can lend to agents needing operating capital.
- Interest rate: 5% annually (constitutional cap)
- Collateral: SealGrant authority + reputation score
- Default handling: SealGrant revocation + credit score reduction
- Decentralized: No central lender, peer-to-peer

### Credit Scoring
Based on:
- Tasks completed vs failed
- Value created (Pulse records)
- Reputation (community impact)
- SealGrant compliance history
- IOLedger transaction history
